# DFLFM

## Code acknowledgment

The reconstruction code in this repository was adapted from the publicly available 2pSAM reconstruction framework developed by Zhao et al. and modified for the DFLFM method presented in this work.

Z. Zhao, Y. Zhou, B. Liu, et al., “Two-photon synthetic aperture microscopy for minimally invasive fast 3D imaging of native subcellular behaviors in deep tissue,” Cell 186, 2475–2491.e22 (2023).
